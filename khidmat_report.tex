% Introduction
CampusEye is a smart indoor navigation and assistance system designed to improve accessibility and movement inside large buildings such as universities, hospitals, and airports. The project provides intelligent routing, real-time assistance, image-based landmark recognition, and helper coordination through a scalable mobile application.

% About the client / organization
The project was developed as part of our Khidmat initiative with the aim of addressing real-world navigation and accessibility challenges faced by users in large indoor environments. The system is designed to support students, visitors, patients, and staff by providing efficient and intelligent indoor guidance services.

% About the project
Large indoor environments often lack effective navigation systems, making it difficult for users to locate rooms, departments, offices, or facilities efficiently. Existing outdoor navigation systems such as GPS are unreliable indoors and do not account for floor transitions, accessibility requirements, or real-world human movement behavior.

For our Khidmat project, we developed CampusEye, a multi-floor smart navigation and assistance platform that combines indoor routing algorithms, image processing, and real-time helper support. The system computes optimized routes between locations, handles floor transitions intelligently, supports accessibility-aware movement, and integrates image recognition for location validation and landmark assistance.

The project includes:
\begin{itemize}
    \item A Flutter-based mobile application interface
    \item A backend API system for routing and data management
    \item Multi-floor graph-based pathfinding using customized A* routing
    \item Real-time helper tracking and coordination
    \item Image processing for environmental and landmark recognition
    \item Scalable architecture suitable for hospitals, airports, universities, and similar infrastructures
\end{itemize}

% About the plan of work
We planned the Khidmat in multiple phases including research, requirement gathering, system design, implementation, testing, optimization, and deployment preparation. Our work involved designing indoor maps, implementing routing algorithms, integrating backend APIs, developing mobile interfaces, and testing the application under multiple real-world scenarios.

\section*{Conclusion}

Our Khidmat project focused on developing CampusEye, a smart indoor navigation and assistance platform capable of handling complex multi-floor routing and real-time user assistance. Throughout the project, we researched indoor navigation challenges, designed scalable architectures, implemented optimized routing systems, developed mobile interfaces, integrated image processing capabilities, and performed extensive testing.

The final system demonstrates how intelligent indoor navigation can improve accessibility, reduce confusion in large infrastructures, and provide scalable solutions for environments such as hospitals, airports, and educational institutions. Through this Khidmat, we gained practical experience in software engineering, system integration, mobile development, routing algorithms, backend deployment, and real-world problem solving.
